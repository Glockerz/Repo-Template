# Architecture — file by file

Normative behaviour lives in [`PHETAMINE.md`](PHETAMINE.md); this file says where
each piece of it lives and what each unit is allowed to touch. If a file is not in
this table it should not exist; if a file in this table is missing, the build will
say so (`CMakeLists.txt` lists sources explicitly, so a missing file is a
configure error, not a surprise at link time).

## Start-up, in order

```
UI: Injector.cs ──▶ shellcode stub (src/inject/stub/stub.c, raw blob)
                      │ maps PHETAMINE.dll by hand (no loader, no relocations)
                      ▼
                    PhetamineEntry(params, loaderBase, image)
                      │ src/dllmain.cpp — records the ParamBlock, starts one thread
                      ▼
                    core::Initialize()                       src/core/core.cpp
                      Image → Offsets → Ipc → Api → DataModel → ScriptContext
                      ▼  inject::RequestMainThreadBootstrap()  ← WH_GETMESSAGE on the
                      │                                        thread that owns the window
                      ▼  core::BootstrapOnMainThread()          (client main thread)
                      LuaState → Environment → Identity → Registry → Scheduler(Heartbeat)
                      → delete PHETAMINE.internal → Canary → Ready → Watchdog
```

## `src/` — PHETAMINE.dll (C++20, MSVC/clang-cl x64, `/MT`)

| Path | Responsibility | Rules it must obey |
|---|---|---|
| `dllmain.cpp` | `DllMain` (normal load) and the exported `PhetamineEntry` (stub load). | Two statements only, plus the hand-off: nothing else may run under the loader lock. |
| `core/core.h/.cpp` | Stage enum, `Initialize`, `Shutdown`, `BootstrapOnMainThread`, `RunCanary`, `RebindOnMainThread`, `WatchdogThread`, the teleport queue, the `Ready` snapshot. | Every failure path calls `Shutdown()`; a half-initialised module is never left running. |
| `common/seh.h/.cpp` | `TryRead/TryWrite/TryReadBytes/TryWriteBytes/GuardedCall`, page queries, the own-image range and the VEH backstop. | Every dereference of client memory goes through here; the VEH **never** swallows a fault (it counts, annotates, and passes it on). |
| `common/log.h/.cpp` | `log::Info/Warn/Error/Fatal/StageError` into an installable sink, `ERROR:<stage>` formatting. | Stack buffer only; the sink contract is "valid for the duration of the call". |
| `common/strings.h` | SSO reads (`ReadSso`), NUL reads, UTF-8⇄UTF-16. | All reads SEH-guarded, all lengths capped at 512. |
| `memory/offsets.h/.cpp` | Load the embedded table, `Get`, `StatusOf`, `MarkProbed`, the resolution cache, version compare. | Unresolved ⇒ `0` ⇒ the dependent feature is off. There is no fallback constant anywhere. |
| `memory/offsets_embedded.json` | The table's source of record (generated from the public dumper; `docs/OFFSETS.md`). | Never hand-edited; regenerated by `tools/offsets/fetch_offsets.mjs`. |
| `memory/offsets_table.inc` | **Generated** C++ rows consumed by `offsets.cpp`. | A build artifact (CMake custom command), not committed. |
| `memory/sigs.h/.cpp` | Signature table (all rows empty by design) + `ResolveSig`, each row tagged with the capability it gates. | A pattern is added only with a behaviour probe that proves it. |
| `memory/scanner.h/.cpp` | `??`-pattern parse, executable-section scan, RIP-relative follow. | Committed executable ranges only; ambiguous matches are refused, not guessed. |
| `memory/pe.h/.cpp` | PE header sanity for the client image and for our own. | Read-only; no writes to the client's headers. |
| `memory/instance_walker.h/.cpp` | `GetDataModel`, `AcquireScriptContext`, name/class/parent/children walks, hidden container. | Every read bounded and SEH-guarded; `IsValidInstance` = descriptor + non-empty class name. |
| `lua/state.h/.cpp` | The `lua::Api` function-pointer table, `ResolveApi` (export → cache → signature → bundled), `AcquireState`, `ProbeBehaviour`, `DumpResolution`. | A pointer is bound only after its resolution path succeeded; every consumer checks for null. |
| `lua/env.h/.cpp` | `BuildEnvironment` (renv/genv/`_G`/`shared`), `PushGenv`, `MergeRegistryIntoGenv`, `ProtectRenv`, `ReleaseEnvironment`, `SetSession`. | One environment per bind; `renv` is never mutated (readonly when the fork allows). |
| `lua/identity.h/.cpp` | Identity read/write, the passed round-trip probe, `GetCallingScript`. | Writes only to threads we own; the capability stays off unless the probe passes. |
| `lua/threads.h/.cpp` | The set of `lua_State*` we created. | SRW-locked; `IsOursCurrent` answers `checkcaller` honestly. |
| `lua/layout.h` | Structural offsets that are **per build** (`kUnset` until filled). | Nothing may read a `kUnset` offset; the feature that needs it stays off. |
| `scheduler/scheduler.h/.cpp` | The job ring, `Drain`, parked/yielding threads, resume budget, health counters. | `Drain` is the only place the VM is touched, and it runs only on the client main thread. |
| `scheduler/rendezvous.h/.cpp` | How the drain gets onto that thread: Heartbeat first, APC probe, reserved frame-site/task-queue, `None`. | Reports the strategy it actually armed; `None` is a reported failure, never a silent one. |
| `executor/executor.h/.cpp` | `Compile`/`Run`/`LoadStringInto`/`StopAll`, `Bytecode` RAII, the `sched::jobs::` handlers, `CurrentScriptThread`. | Bytecode is freed with the client's allocator or leaked loudly — never with ours. |
| `ipc/protocol.h/.cpp` | Opcodes (X-macro), framing, the log ring, `LogLine`. | The opcode table is duplicated in C# on purpose and checked by `tools/verify.mjs`. |
| `ipc/pipe_server.h/.cpp` | The named pipe: one acceptor, one reader, one writer, the job-id map. | The reader never touches the VM: it compiles on a worker and enqueues. |
| `native_api/api.h` | Capability enum + table, `Registrar`, `Add`, the shared argument helpers, workspace root. | One capability decides whether a closure is registered at all. |
| `native_api/registry.def` | The single registration table: one row per UNC function. | A row is a promise (implementation + documentation + capability); `verify.mjs` enforces all three. |
| `native_api/registry.cpp` | Builds the closure table from `registry.def`, merges it into genv, installs `PHETAMINE` (and `.internal` for the bootstrap). | Dotted names create a *shadow* subtable; engine tables are never mutated. |
| `native_api/{env,identity,closures,metatable,instances,net,fs,misc}.cpp` | The `l_<symbol>` implementations, one file per registry translation unit. | Off-capability ⇒ not registered. Unresolvable ⇒ raise with the capability named, never a plausible stub. |
| `net/client.h/.cpp` | WinHTTP request/response, proxy setting, the websocket entry point. | No loopback listener; nothing blocks the drain thread. |
| `inject/param.h` | The `ParamBlock` ABI shared with the injector. | Versioned, POD, fixed-size strings; validated before use. |
| `inject/loader.h/.cpp` | `Start`, the param accessors, the main-thread bootstrap (one-shot `WH_GETMESSAGE`), and the self-unmap trampoline. | The bootstrap fails closed with `ERROR:Bootstrap` when no main thread can be reached. |
| `inject/stub/stub.c` | The freestanding loader: PEB walk, relocations, imports, section protections, `PhetamineEntry`. | No CRT, no relocations, data merged into `.text`, ≤ 16 KiB (`tools/gen/shellcode_blob.mjs` enforces it). |
| `inject/blob/README.md` | The three-way contract between CMake, the generator and the injector. | Kept in step with the code; the generator's checks are the executable version of it. |
| `CMakeLists.txt` | Targets (`PHETAMINE`, `PHETAMINEStub`), `/MT`, `/EHa`, generated inputs, the post-build module check. | No relocations, no hotpatch, no trampolines: the image check fails the build otherwise. |

## `ui/PHETAMINEUI/` — WinForms front end (Debug only)

| File | Responsibility |
|---|---|
| `Program.cs` | Entry point; every unhandled exception is shown, never swallowed. |
| `MainForm.cs` | The window: PID picker, Inject, script box, EXECUTE/STOP/UNLOAD/PING, log pane, capability panel. |
| `PipeClient.cs` | The transport and the opcode table (checked against `protocol.h`). One reader thread; events only. |
| `Injector.cs` | `ParamBlock` layout, process discovery, `VirtualAllocEx`/`WriteProcessMemory`/`CreateRemoteThread`. |
| `PeImage.cs` | The minimal PE reader: x64? DLL? relocations? lay the image out for the stub. |
| `PHETAMINEUI.csproj` | `net8.0-windows`; **fails the build** for any configuration other than Debug. |
| `README.md` | What the UI is not, and why a Release build is refused. |

## `tools/` — host-side, dependency-free Node (≥ 22.18)

| Tool | Responsibility |
|---|---|
| `offsets/fetch_offsets.mjs` | Fetch/normalise the public dumper into `src/memory/offsets_embedded.json`; `--from <fixture>` works offline. |
| `offsets/map_offsets.mjs` | The `KEYMAP` (65 keys): dumper path → our key, kind, and the `UNPUBLISHED` VM keys. |
| `offsets/gen_offsets_header.mjs` | Emit/verify `offsets_table.inc`. |
| `gen/shellcode_blob.mjs` | Turn the linked stub into the raw blob; refuses relocations, an out-of-`.text` entry, or > 16 KiB. |
| `gen/check_module.mjs` | Post-build: the linked DLL must be x64, reloc-free, and export `PhetamineEntry`. |
| `gen/crossref.mjs` | Offline name check across `src/`: every `ns::name` and every `api.<member>` must be declared somewhere. |
| `verify.mjs` | The five repository invariants (registry↔docs, capabilities, offset keys, IPC opcodes, deleted artifacts). |
| `selftest.mjs` | Runs every host-runnable check (`npm test`). |

## One `EXECUTE`, end to end

```
UI: Execute(id, source)  ── frame ──►  pipe server reader (worker thread)
                                          └─ exec::Compile(source)      [client's luau_compile]
                                             └─ scheduler::Enqueue(RunScript{bytecode, genvRef, identity})
──── next frame, client main thread ──────────────────────────────────────────────────────────
sched::Drain()
  ├─ T = lua_newthread(mainState)
  ├─ luau_load(T, "=PHETAMINE", bytecode, size, genvRef)   → bytecode freed with crt.free
  ├─ identity::Set(T, kElevated) when the capability is on
  ├─ lua_resume(T, mainState, 0)
  │    ├─ kOk    → report ok, lua_resetthread(T), threads::Remove(T)
  │    ├─ kYield → ParkYielded(T, deadline); resumed by ResumeDue() under the frame budget
  │    └─ error  → lua_tostring(T, -1) → PostExecResult(id, ok=false, message)
  └─ every result goes back through the IPC writer thread, never from inside the VM call
```
